# The Side

A public, open-source writing space where anyone can share their thoughts, notes, essays, stories, and ideas.

## Vision

The Side is a collaborative writing platform that turns the web into a shared public notebook. It invites people to publish ideas, build on each other's thinking, and keep a living archive of community knowledge.

## Features

- Public writing feed
- Story, essay, idea, and note publishing
- Simple daily writing experience
- Topic and category tagging
- Community-friendly, open-source structure
- Easy contribution workflow

## Tech stack

- Next.js
- TypeScript
- Tailwind CSS

## Getting started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run the app locally:

   ```bash
   npm run dev
   ```

3. Open http://localhost:3000

## Project scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```
